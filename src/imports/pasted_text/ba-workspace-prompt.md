# Master Prompt for Figma Make

# Universal Business Analyst Workspace (Enterprise OS)

Design an enterprise-grade **Business Analyst Workspace** that serves as a complete operating system for managing the entire product lifecycle, from discovery through production release.

This is **not just a UAT dashboard**. It is a configurable BA platform that can be reused for any software product, including SaaS, AI applications, mobile apps, ERP, CRM, internal systems, APIs, and websites.

The workspace should support multiple concurrent projects while maintaining a clean, modern SaaS experience inspired by Linear, Atlassian, Notion, GitHub, Vercel, Jira, and Monday.com.

The interface should emphasize clarity, decision-making, traceability, and collaboration rather than excessive data density.
